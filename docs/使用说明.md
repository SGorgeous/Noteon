# Noteon 使用说明

## 启动

双击 `Noteon.cmd`（或 `Noteon.vbs`，不弹黑框）。程序会常驻托盘，图标是蓝底白色便签。

- 第一次启动：桌面出现一张欢迎便签，同时打开控制台。
- 之后启动：恢复上次的卡片和位置；需要控制台就点托盘图标。

托盘右键：新建卡片、显示/隐藏全部、全部置顶、解除鼠标穿透、退出。

## 新建卡片

在控制台「卡片」页点任意插件磁贴，桌面上就会出现一张新卡片。

| 插件 | 怎么用 |
| --- | --- |
| **便签** | 直接写。`预览` 看 Markdown；`A−/A+` 调字号；自动保存。 |
| **文本** | 点文件夹图标选文件，或把 txt / md / 代码拖进来；改完自动写回。`Ctrl+S` 立即保存。 |
| **图片参考** | 把图片拖进来或点打开。滚轮缩放、按住拖动、双击在「适应窗口 / 1:1」间切换。工具栏可开三分网格、吸管、水平翻转；两张以上图可开「对比」，拖动分割线看左右差异。 |
| **文件夹映射** | 选一个文件夹钉住。双击文件夹进入，双击文件用对应卡片打开；把文件拖进卡片会复制到当前文件夹。 |
| **网页** | 输入网址或拖入本地 HTML。地址栏回车打开；支持前进后退、缩放、用系统浏览器打开。 |
| **文件中转** | 文件拖进来暂存；按住条目拖到桌面、聊天窗口或别的软件。条目可「复制路径」。 |

## 右键菜单

桌面或文件夹空白处右键 → **在 Noteon 新建** → 选卡片类型。

- 文件夹空白处右键时，「文件夹映射」会自动打开当前文件夹
- Windows 11 默认菜单会把它收在 **「显示更多选项」** 里；按 `Shift+F10` 也可以直接打开旧版菜单
- 便携版首次启动会自动注册到当前用户，控制台 → 设置 → **资源管理器右键菜单** 可以关闭

## 卡片操作

- **移动**：拖标题栏。靠近屏幕边缘 / 其它卡片会自动吸附（可在设置里关）。
- **缩放**：鼠标移到卡片左右边、底边或底角（边框内 6px 左右），出现箭头后拖动。上边留给标题栏拖动。
- **置顶**：标题栏图钉。置顶的卡片始终在其它窗口上面。
- **更多**（`⋯`）：换主题、不透明度、重命名、鼠标穿透、重新加载、开发者工具、关闭。
- **鼠标穿透**：卡片会忽略鼠标（适合把参考图钉在屏幕上不挡操作）。恢复：托盘 → 解除全部鼠标穿透。
- **隐藏**：标题栏眼睛图标（或 `Ctrl+H`）。卡片从桌面消失但不删除，托盘「显示全部卡片」或控制台「显示」可恢复。
- **关闭**：× 或 `Ctrl+W`。卡片记录会删除，内容文件不受影响。

## 主题

控制台「主题」：选预设（墨夜 / 雾白 / 纸页 / 极光 / 樱粉 / 林间），再微调强调色、背景色、不透明度、圆角、背景模糊。右边是实时预览，所有卡片会立即跟着变。

某张卡片想单独用别的主题或透明度：卡片 `⋯` → 主题 / 不透明度。全局再改也不会覆盖这张卡片的单卡设置；想清掉单卡覆盖，用主题页的「清除单卡覆盖」。

## 控制台

- **卡片**：新建、显示、置顶、关闭、全部显示 / 隐藏。
- **主题**：见上。
- **设置**：启动恢复、默认置顶、吸附、任务栏、启动打开控制台；数据目录、插件目录、DevTools。
- **关于**：版本与插件接口摘要。

## 数据与重置

卡片、位置、主题、插件状态都在程序目录里（便携，不写 C 盘）：

```
<Noteon 目录>\data\board.json
```

- 备份：退出 Noteon 后复制整个 `data` 目录。
- 重置：退出 Noteon 后删除程序目录下的 `data` 目录。
- 旧版本升级：首次启动会自动把 `%APPDATA%\Noteon\board.json` 迁移过来，并清理旧目录。

## 常见问题

**关掉卡片后程序还在？**  
是。Noteon 常驻托盘，方便随时新建；要完全退出用托盘「退出 Noteon」。

**卡片上的字很小 / 很大？**  
拖边角缩放卡片；文本 / 便签可以单独调字号。系统缩放 150% 下也正常。

**网页卡片为什么不显示某个网站？**  
部分站点禁止被嵌入，或需要登录 / 特殊权限；点地址栏右边的「用系统浏览器打开」即可。网页内容在卡片里是一块独立原生区域，所以底部有一条 18px 状态栏。

**图片拖出 / 文件拖出？**  
一次拖一个（Electron 限制）。多个文件请用「复制路径」或先复制到文件夹。

**能打包成 exe 吗？**  
当前用 `runtime/electron` 直接启动。需要独立 EXE 时再打包。
