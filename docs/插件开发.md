# Noteon 插件开发

卡片壳负责窗口、拖动、缩放、主题、持久化和 IPC；插件只拿到一个 `root` 元素，
在里面画自己的界面，用 `ctx.api` 做文件、窗口、卡片相关的事。

## 1. 目录

```
plugins/
  hello/
    plugin.json     必需，清单
    index.js        必需，渲染进程入口（经典脚本，不是 ES Module）
    style.css       可选，在 plugin.json 里用 "style" 声明后自动加载
    icon.svg        可选，卡片标题栏图标
    main.cjs        可选，主进程处理器（见第 6 节）
```

新建后，在控制台「设置」里点 **重新加载插件**，或重启 Noteon。

## 2. plugin.json

```json
{
  "id": "hello",
  "name": "你好",
  "description": "一句话说明这个卡片能做什么",
  "version": "1.0.0",
  "icon": "icon.svg",
  "entry": "index.js",
  "style": "style.css",
  "defaultSize": [360, 420],
  "minSize": [260, 200],
  "order": 100,
  "accent": "#6ea8fe"
}
```

| 字段 | 说明 |
| --- | --- |
| `id` | 唯一，`[a-zA-Z0-9_-]`，也就是目录名 |
| `name` / `description` | 控制台与卡片标题的显示名 / 说明 |
| `icon` | 相对插件目录；通过 `noteon-plugin://<id>/icon.svg` 提供 |
| `entry` | 渲染进程入口，经典脚本 |
| `style` | 可选样式表，通过 `noteon-plugin://<id>/style.css` 加载 |
| `defaultSize` / `minSize` | CSS 像素，窗口有系统缩放时会自动换算 |
| `order` | 控制台里的排序，小的靠前 |
| `accent` | 控制台磁贴的强调色 |

## 3. index.js

```js
Noteon.define({
  id: 'hello',
  mount(ctx) {
    const { root, api } = ctx;
    root.innerHTML = '<div class="hello">你好</div>';
    api.setStatus('hello');
    return {
      unmount() {
        // 清理定时器 / 事件监听 / 资源
      },
    };
  },
});
```

- `mount(ctx)` 在卡片窗口里执行，可以返回 `{ unmount }`，也 `await` 异步初始化。
- 插件脚本是**普通 script**，不是 module；需要多个文件时自己用 `<script>` 或把代码合并。
- 插件目录内的其它资源用 `noteon-plugin://<id>/文件名` 访问。
- 样式写在 `style.css` 里，并在 `plugin.json` 声明 `style`；页面 CSP 不允许外域样式。

## 4. ctx

| 属性 | 说明 |
| --- | --- |
| `ctx.root` | 插件独占的 DOM 容器，占满卡片正文 |
| `ctx.card` | 当前卡片（只读快照） |
| `ctx.manifest` | 清单 |
| `ctx.theme` | 当前解析后的主题对象 |
| `ctx.icon(name, size)` | 内置线性图标，见 `renderer/shared/icons.js` |
| `ctx.util` | `escapeHtml` / `formatSize` / `formatTime` / `ext` / `kind` / `iconFor` |
| `ctx.onDrop(fn)` | 拖入文件时 `fn(paths, event)` |
| `ctx.onTheme(fn)` | 主题变化 |
| `ctx.onCardUpdate(fn)` | 卡片标题 / 置顶 / 主题等变化 |
| `ctx.api` | 下面这张表 |

## 5. ctx.api

### 卡片

| 方法 | 说明 |
| --- | --- |
| `api.state` | 当前插件状态（只读，`card.state`） |
| `api.saveState(patch)` | 浅合并进卡片状态并持久化，适合存路径、缩放、列表 |
| `api.title(text)` | 改标题 |
| `api.close()` | 关闭当前卡片 |
| `api.openCard({plugin, state, title})` | 新建卡片 |
| `api.openFile(path)` | 按扩展名在新卡片里打开（图片 / 文本 / HTML），其它交给系统 |
| `api.showCard(id)` / `api.listCards()` | 显示 / 列出卡片 |

### 文件与对话框

`pickFolder()`、`pickFiles({filters, multi})`、`saveFileDialog({defaultPath, filters})`、
`messageBox({message, detail, buttons})`、`readDir(dir, showHidden)`、`readText(path, maxBytes)`、
`writeText(path, text)`、`stat(path)`、`exists(path)`、`copyInto(paths, destDir)`、
`listDrives()`、`reveal(path)`、`openPath(path)`、`openUrl(url)`、`copy(text)`、`dragFile(path)`。

返回统一是 `{ ok, ... }` 或 `string | null`：

```js
const r = await api.readDir('D:\\pics', false);
if (r.ok) r.entries.forEach((e) => console.log(e.name, e.isDir));
```

### 图片

```js
const img = await api.loadImage('D:\\ref.png'); // 也支持 http(s) / data:
img.url;      // blob: 地址，可直接塞给 <img>
img.width; img.height; img.name;
img.revoke(); // 不再需要时释放
```

### 菜单 / 通知

```js
const picked = await api.menu([
  { id: 'a', label: '选项 A', type: 'checkbox', checked: true },
  { type: 'separator' },
  { id: 'b', label: '选项 B' },
], x, y);

api.toast('已保存');
api.setStatus('12 项 · 3.4 MB'); // 传空字符串隐藏状态条
```

### 插件设置与主进程

```js
const prefs = await api.pluginSettings();        // 同一插件的全局设置
await api.savePluginSettings({ theme: 'dark' });

const res = await api.invoke('doSomething', { id: 1 }); // 调 main.cjs 里的处理器
```

### 网页内容层（高级）

网页卡片使用主进程的 `WebContentsView`，普通插件不需要这些：

`api.webLoad(input, rect)`、`api.webBounds(rect)`、`api.webAction('back'|'forward'|'reload'|'stop')`、
`api.webZoom(factor)`、`api.webVisible(bool)`、`api.webDevTools()`、`api.webDestroy()`，
以及 `api.on('web:state', fn)` 订阅导航状态。

## 6. main.cjs（可选）

需要读系统信息、打开特权资源或做重计算时，把逻辑放到主进程：

```js
module.exports = {
  activate({ manifest, store, cards, dir }) {
    // 插件被扫描时调用一次
  },
  handlers: {
    async doSomething(args, ctx) {
      // ctx: { store, cards, dir, sender }
      return { ok: true, echo: args };
    },
  },
};
```

渲染进程用 `api.invoke('doSomething', args)` 调用。`main.cjs` 可以 `require` Node 模块；
`index.js` 不行——它运行在 `contextIsolation` 的渲染进程里，只能通过 `ctx.api` / `api.invoke`。

## 7. 约定与建议

- 状态要小：`saveState` 会写进 `board.json`，不要把大段文本 / base64 图片塞进去。
- 文件读写走 `api`，不要尝试 `require('fs')`。
- 卡片可能会被随时关闭：异步回调前判断 `root.isConnected`，在 `unmount` 里清定时器。
- 主题用 CSS 变量：`--fg`、`--muted`、`--border`、`--accent`、`--accent-soft`、`--hover`、`--bg`。
- 字体：`var(--font-ui)` / `var(--font-mono)`，不要写死系统字体栈。
- 拖入文件由 `ctx.onDrop` 统一接；拖出单文件用 `api.dragFile(path)`。

## 8. 调试

- 卡片 `⋯` → **重新加载卡片**：改完 `index.js` / `style.css` 立即看效果。
- 卡片 `⋯` → **开发者工具**：打开这一卡的 DevTools。
- 控制台 → **DevTools**：调控制台页面。
- `runtime\electron\electron.exe . --demo`：建 6 张示例卡并保持运行，适合调布局。
- `runtime\electron\electron.exe . --smoke`：自动截图 + 交互自测，产物在 `out\smoke\`。
