插件接口

在 plugins/<id>/ 里放 plugin.json、index.js，需要样式再加 style.css。渲染进程通过 ctx.api 拿到文件、窗口、卡片能力。

Noteon.define({
  id: 'hello',
  mount(ctx) {
    const { root, api } = ctx;
    root.innerHTML = '<h1>你好</h1>';
    // api.readDir / api.openCard / api.saveState / api.toast ...
    return { unmount() {} };
  }
});
